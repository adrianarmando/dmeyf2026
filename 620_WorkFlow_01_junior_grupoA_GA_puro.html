🧪 Versión Híbrida (WF9100) Manual + GA

Combina 22 variables de negocio prefijadas (estrés financiero, consolidación de tarjetas, ticket promedio) con búsqueda genética. Las fórmulas de dominio actúan como "Warm Start" para la población evolutiva.

🧬 Versión Pura (WF9101) 100% Autónomo

Cero hipótesis manuales previas. El algoritmo genético (gramEvol) recibe únicamente las columnas crudas del banco y asume la responsabilidad exclusiva de explorar el espacio algebraico y sintetizar las interacciones predictivas óptimas (GA_Feature_1 a 5).

Hipótesis Científica a Comprobar en Kaggle: ¿Alcanza un modelo con features puramente evolucionadas mediante GA un score comparable o superior al modelo enriquecido con reglas manuales de banca minorista?

Al no existir transformaciones manuales previas, el algoritmo genético extrae el espacio terminal de variables numéricas originales directamente tras las etapas de Catastrophe Analysis (CA) y Data Drifting (DR):

Filtro de Terminales Crudas

# Selección estricta de variables crudas originales
excluir_GA <- c("numero_de_cliente", "foto_mes", "clase_ternaria", "clase01", "azar", "fold_train", "fold_final_train")
candidatas_GA <- setdiff(colnames(dataset), excluir_GA)

# Filtrar únicamente columnas numéricas

candidatas_GA <- candidatas_GA[son_numericas]

# Excluir fechas

# Control del espacio de búsqueda (máx 60 terminales para forzar todas las variables)

  candidatas_GA <- sample(candidatas_GA, MAX_TERMINALES)
}

4. Gramática Formal BNF y Función de Fitness

Gramática BNF de Expresiones

Permite sumas, restas, multiplicaciones y cocientes protegidos entre cualquier par de atributos crudos: 

<expr> ::= <op>
<op>   ::= <op> + <op> |
           <op> - <op> |
           <op> * <op> |
           protected_div(<op>, <op>) |
           protected_log_diff(<op>, <op>) |
           <var>
<var>  ::= mcaja_ahorro | mpayroll | ...

Operadores Aritméticos Protegidos

Evitan divisiones por cero, Inf o NaN: 

protected_div <- function(x, y) {
  res <- x / (y + 1e-5)
  res[is.na(res) | is.infinite(res)] <- 0
  res
}

protected_log_diff <- function(x, y) {
  res <- log(abs(x - y) + 1)
  res[is.na(res) | is.infinite(res)] <- 0
  res
}

Función de Aptitud (Fitness) con LightGBM Univariado

Para cada expresión R generada por la población, se calcula un modelo LightGBM univariado rápido sobre una partición temporal local de 50.000 filas (meses anteriores a 202107). La métrica optimizada es el costo 1 - AUC: 

fitness_gramEvol <- function(expr) {
  valores <- tryCatch(eval(expr, envir = dataset), error = function(e) NULL)
  if (is.null(valores)) return(1)

  val_tr <- valores[idx_tr_GA]
  val_finitos <- val_tr[is.finite(val_tr)]
  if (length(val_finitos) == 0 || length(unique(val_finitos)) <= 1) return(1)

  dtr_ga  <- lgb.Dataset(data = matrix(val_tr, ncol = 1), label = y_tr_GA, free_raw_data = TRUE)
  dval_ga <- lgb.Dataset(data = matrix(valores[idx_val_GA], ncol = 1), label = y_val_GA, free_raw_data = TRUE)

  modelo_ga <- tryCatch({
    lgb.train(
      params = list(objective = "binary", metric = "auc", learning_rate = 0.1, num_threads = 1, verbosity = -1),
      data = dtr_ga, valids = list(valid = dval_ga),
      nrounds = 50, early_stopping_rounds = 10, verbose = -1
    )
  }, error = function(e) NULL)

  if (is.null(modelo_ga) || is.null(modelo_ga$best_score) || is.na(modelo_ga$best_score)) return(1)
  1 - modelo_ga$best_score
}

🛡️ 4.8 Blindaje Defensivo Anti-Leakage en 3 Capas

Detección y Corrección de Falla Crítica: En versiones preliminares experimentales (v2), la creación prematura de clase01 en dataset provocaba que en FEhist se generase clase01_delta1 = clase01[t] - clase01_lag1[t-1]. Al entrar en campos_buenos, LightGBM memorizaba el target actual alcanzando un AUC artificial de 0.999998 (Data Leakage total), colapsando luego en Kaggle (mes 202109).

Esta versión implementa una arquitectura defensiva en 3 niveles:

  • 1. Aislamiento Volátil del Target en GA: Las etiquetas de fitness se computan en vectores temporales en memoria (y_tr_GA y y_val_GA) sin inyectar clase01 en dataset, con verificación explícita de remoción.
  • 2. Protección en FE Histórico: Se añade clase01 a la lista de exclusiones de cols_lagueables para impedir que sea lagueada bajo cualquier circunstancia.
  • 3. Filtro Regex en Modelado: campos_buenos <- campos_buenos[!grepl("^clase", campos_buenos)] elimina cualquier predictor residual relacionado con el target antes de entrenar LightGBM.
# Capa 1: Target volátil en GA (sin inyectar en dataset)
y_tr_GA  <- ifelse(dataset$clase_ternaria[idx_tr_GA] %in% c("BAJA+1", "BAJA+2"), 1L, 0L)
y_val_GA <- ifelse(dataset$clase_ternaria[idx_val_GA] %in% c("BAJA+1", "BAJA+2"), 1L, 0L)
if ("clase01" %in% colnames(dataset)) dataset[, clase01 := NULL]

# Capa 2: Protección estricta en FEhist
cols_lagueables <- copy(setdiff(colnames(dataset), c("numero_de_cliente", "foto_mes", "clase_ternaria", "clase01", "azar")))

# Capa 3: Filtro regex definitivo en modelado
campos_buenos <- campos_buenos[!grepl("^clase", campos_buenos)]

Presión Selectiva Aumentada (Elitismo y Mutación)

Se implementa un 50% de elitismo estricto para preservar la mitad superior de la población e impedir regresiones evolutivas, combinado con 15% de mutación para sostener la diversidad genética: 

ge_res <- GrammaticalEvolution(
  grammarDef      = bnf_grammar,
  evalFunc        = fitness_gramEvol,
  popSize         = PARAM$GA$popSize,
  iterations      = PARAM$GA$iterations,
  terminationCost = 0.10,
  seqLen          = PARAM$GA$seqLen,
  max.depth       = PARAM$GA$max.depth,
  
  # Nuevos parámetros de presión selectiva
  elitism         = as.integer(PARAM$GA$popSize * 0.50),
  mutationChance  = 0.15,
  
  monitorFunc     = function(result) {
    cat(sprintf("Gen %2d | Mejor Costo: %.5f (AUC: %.5f)\n",
                result$population$currentIteration,
                result$best$cost,
                1 - result$best$cost))
  }
)
